# Phase 2 — SmallVillage asset kit

The kit is the reusable library of everything the village is made of. Phase 3 (layout) places these assets; Phase 4 exports them to the browser.

```sh
blender -b --factory-startup --python blender/rebuild/kit/build_kit.py                       # builds kit/sv_kit.blend
blender -b --factory-startup --python blender/rebuild/kit/build_kit.py -- --sheet          # + review renders in kit/renders
```

`sv_kit.blend` is regenerated by the script, so it is not committed. It is a Blender **asset library**: every asset is marked, catalogued and tagged, and can be dragged in from the Asset Browser.

## One palette material

- Every kit mesh uses the single material `SV kit palette`, a toon shader reading a 16×16 **palette texture**. Each face is UV-mapped to the centre of one colour cell (a "slot", such as `bark`, `leaf_l` or `wheat_ripe`).
- There are four palette images: `spring`, `summer`, `autumn` and `winter`. Season-dependent slots (leaves, grass, willow, hedge) change colour between them, and all other slots stay identical.
  - **Seasonal colour changes by swapping one texture**, in Blender and in three.js.
- Seasonal *shape* changes (bare trees, crop growth stages, snow) are separate asset variants.
- **For the web:** one material and one tiny texture means almost the whole village can be drawn in very few batches (instancing or `BatchedMesh`).
- Slot names and colours live in `palette.py`, which is the single source for Blender and for the future web exporter.

## Asset metadata (custom properties, exported as glTF extras)

| Property | Meaning |
| --- | --- |
| `sv_kind` | `tree`, `crop`, `ground`, `building`, `prop`, `vehicle`, `animal` |
| `sv_family` | e.g. `poplar`, `willow`, `wheat`, `maize` |
| `sv_variant` | Index for random choice |
| `sv_state` | `leafy` / `bare` for trees; growth stage for crops |
| `sv_lod` | 0 near (< 40 m), 1 middle (40–150 m), 2 far (> 150 m) |
| `sv_months` | Months in which this state appears (crops and trees), e.g. `"3,4"` |

| Reed / cattail clump (sparse) | ≤ 200 | — | — |
| House module | ≤ 3k | ≤ 600 | ≤ 60 |

The sheet render reports actual counts; anything over budget is flagged.

# Phase 2 — SmallVillage asset kit

The kit is the reusable library of everything the village is made of. Phase 3 (layout) places these assets; Phase 4 exports them to the browser.

```sh
blender -b --factory-startup --python blender/rebuild/kit/build_kit.py                       # builds kit/sv_kit.blend
blender -b --factory-startup --python blender/rebuild/kit/build_kit.py -- --sheet          # + review renders in kit/renders
```

`sv_kit.blend` is regenerated by the script, so it is not committed. It is a Blender **asset library**: every asset is marked, catalogued and tagged, and can be dragged in from the Asset Browser.

## One palette material

- Every kit mesh uses the single material `SV kit palette`, a toon shader reading a 16×16 **palette texture**. Each face is UV-mapped to the centre of one colour cell (a "slot", such as `bark`, `leaf_l` or `wheat_ripe`).
- There are four palette images: `spring`, `summer`, `autumn` and `winter`. Season-dependent slots (leaves, grass, willow, hedge) change colour between them, and all other slots stay identical.
  - **Seasonal colour changes by swapping one texture**, in Blender and in three.js.
- Seasonal *shape* changes (bare trees, crop growth stages, snow) are separate asset variants.
- **For the web:** one material and one tiny texture means almost the whole village can be drawn in very few batches (instancing or `BatchedMesh`).
- Slot names and colours live in `palette.py`, which is the single source for Blender and for the future web exporter.

## Asset metadata (custom properties, exported as glTF extras)

| Property | Meaning |
| --- | --- |
| `sv_kind` | `tree`, `crop`, `ground`, `building`, `prop`, `vehicle`, `animal` |
| `sv_family` | e.g. `poplar`, `willow`, `wheat`, `maize` |
| `sv_variant` | Index for random choice |
| `sv_state` | `leafy` / `bare` for trees; growth stage for crops |
| `sv_lod` | 0 near (< 40 m), 1 middle (40–150 m), 2 far (> 150 m) |
| `sv_months` | Months in which this state appears (crops and trees), e.g. `"3,4"` |

## Buildings: how they are put together

`kit_buildings.py` writes every module into a `MeshWriter` in its own frame (front facing -Y, ground at z = 0), so modules can be merged into one courtyard-plot mesh with the single palette material.

- **Courtyard plot frame:** the lane side is at y = 0, with the gate. The main house is at the back, facing the yard, the side wing runs along the east wall, and the shed stands against the west wall. The footprint is stored in `sv_footprint`, so Phase 3 can rotate each plot to its lane.
- **Detail from the photographs:**
  - Facades: white tile and grey render facades, with unfinished grey gable ends that carry a dark rain-streak band, and burgundy plinths.
  - Trim: gold, ochre and burgundy eave bands, and the glazed upper corridor over a white-tile parapet.
  - Doors: teal door screens, the spring-festival couplets and 福 squares.
  - Roofs: flat roofs with steel railings, and gable roofs with alternating tile courses and a ridge cap.
  - Fixtures: downpipes and AC units.
  - Gates and sheds: red gates with gold studs and a sign board, and blue corrugated sheds.
- Snow on roofs is planned as a shader effect on upward-facing surfaces (Phase 8), not as separate meshes.
- Couplet and sign text is not modelled. A small decal texture can add the characters later.

## Infrastructure: how it fits together

`kit_infra.py` builds linear modules (roads, alley, field path, ditches, river) that run along local +Y from y = 0 to `sv_length` and are centred on x = 0, so Phase 3 can chain them end to end. Junctions are square slabs.

- **Water sits below ground.** Ditch and river channels are cut below z = 0, so the Phase 3 terrain must be lowered or opened along their footprint. Grass flanges on the modules overlap the terrain edge to hide the seam.
- **Water surfaces use the `water` palette slot.** The web exporter can split those faces onto the animated water shader.
- **Wires are not meshes in the kit.** Poles store their insulator positions in `sv_wire_attach`, and `catenary()` returns the sagging points between two poles. The layout phase builds wire curves, or the browser draws them as lines.
- **From the photographs:**
  - Roads: concrete slab roads with dark joints, hairline cracks and dirt shoulders, plus the herringbone brick alley beside the house.
  - Bridges: white balustraded culvert bridges (photo 13).
  - Utilities: poles with white-painted bases and meter boxes, and solar street lamps.
  - Fields: small white well huts with peaked roofs and white field stakes.
